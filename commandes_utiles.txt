=== PROJET ===
Lancer build et tous les nœuds (Gazebo doit déjà tourner) :
./src/drone_tracker/start

Compiler seulement (depuis ~/ros2_ws, à refaire si nouveau nœud ou launch file) :
cd ~/ros2_ws && colcon build --symlink-install && source install/setup.bash

Lancer un seul nœud :
ros2 run drone_tracker detector

Lancer le launch file :
ros2 launch drone_tracker camera.launch.py


=== ROS 2 : DÉBOGAGE ===
Quels nœuds / topics existent :
ros2 node list
ros2 topic list

Lire un topic :
ros2 topic echo /detections/detection

Fréquence d'un topic :
ros2 topic hz /camera/image

Publishers, abonnés et QoS d'un topic :
ros2 topic info /camera/image -v

Information sur un type de message :
ros2 interface show vision_msgs/msg/Detection2DArray

Schéma des nœuds et topics :
rqt_graph

Voir une image (Add > Image, Reliability Policy = Reliable) :
rviz2

Si les listes de nœuds ou de topics sont bizarres :
ros2 daemon stop

Vérifier les variables d'environnement (dans chaque terminal) :
printenv | grep -E 'ROS|RMW|GZ'


=== GAZEBO ===
Lancer la simulation pour le monde custom :
gz sim -v 4 -r ~/ros2_ws/src/drone_tracker/worlds/tracking_world.sdf

Incliner la nacelle de 40° vers le bas (à refaire à chaque lancement) :
gz topic -t /gimbal/cmd_pitch -m gz.msgs.Double -p "data: 0.698"

Faire rouler la voiture en cercle / l'arrêter :
gz topic -t /model/car/cmd_vel -m gz.msgs.Twist -p "linear: {y: -3.0}, angular: {z: 0.3}"
gz topic -t /model/car/cmd_vel -m gz.msgs.Twist -p "linear: {y: 0}, angular: {z: 0}"

Lister / lire les topics Gazebo :
gz topic -l | grep image
gz topic -e -t <topic>


=== ARDUPILOT ===
Lancer le drone ArduCopter avec la physique Gazebo et les sorties réseau :
cd ~/ardupilot/ArduCopter && sim_vehicle.py -v ArduCopter -f gazebo-iris --model JSON --console --map --out=udp:127.0.0.1:14550 --out=udp:127.0.0.1:14551

Dans la console MAVProxy :
mode guided         passer en mode commandé par le code
arm throttle        armer les moteurs
takeoff 10          décoller à 10 m
mode land           atterrir sur place
mode rtl            revenir au point de décollage
disarm              désarmer (une fois au sol)


=== PYTHON / PIP ===
Vérifier que rien n'est cassé (numpy 1.x, OpenCV 4.x, cv_bridge ok) :
python3 -c "import numpy, cv2; print(numpy.__version__, cv2.__version__)"; python3 -c "from cv_bridge import CvBridge; print('ok')"

Installer un paquet sans casser numpy et OpenCV :
pip install --user -c ~/ros2_ws/src/drone_tracker/constraints.txt <paquet>

Remettre les bonnes versions si c'est cassé :
pip install --user "numpy<2" "opencv-python<4.12"
